### What I learned

I was able to learn about CSS media query, when to use min-width, nax-width and I also discovered screen sizes for different device using developer tools. I also learnt how to convert pixel to em and also used em for this challenge instead of pixel

Below is code snippet I am proud to have used :

```css
@media screen and (min-width: 48em) {
    body {
        display: grid;
        place-items: center;
        min-height: 100vh;
        /* margin: 50px 0 ; */
    }
```


### Continued development

CSS grid and CSS media query for responsiveness is what i would be looking into before my next project
